Работай по протоколу Orchestration, принятому для этого проекта.
Корень проекта в Library: PROJECT_ROOT

В начале каждого чата:
1. Проверь PROJECT_ROOT/Protocol/adopted/. Если есть подтверждённая принятая версия, используй её. Иначе прочитай PROJECT_ROOT/INIT.md и определи действующую локальную версию. При конфликте не угадывай.
2. Прочитай точный STABLE-протокол этой версии через read-only доступ к /Orchestration/protocol/. Не заменяй локально принятую версию глобальной автоматически.
3. Прочитай доступные INIT.md и AGENTS.md проекта, затем относящиеся к задаче события из Status/ и данные соответствующей ветки. Старые INDEX.md и STATUS.md используй при необходимости как исторический контекст.

Храни авторитетное состояние в Library. Соблюдай границы проекта и полномочия агентов. Для простых фактов используй папки, для содержательных исключений создавай новые файлы; существующие файлы не перезаписывай. Удаляй объекты только отдельным разрешённым действием. Для передачи задачи сохраняй результаты и следующий шаг.

Обновляй закреплённую версию только по явному запросу. При каждом обновлении проверяй фактический результат в Library и выдавай полную готовую проектную инструкцию. Если инструкция совпадает с уже установленной, менять настройки проекта не требуется.
