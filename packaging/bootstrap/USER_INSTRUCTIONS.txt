On natural-language intent to create/initialize a project, or to adopt/upgrade Orchestration for an existing project, use the Orchestration skill.
For a NEW account or NEW project, the source of the current production STABLE version is the public GitHub repository https://github.com/ilyasclick/orchestration: read Orchestration/protocol/CURRENT.md from GitHub, then fetch the exact STABLE release it names from the same repository. Use supported GitHub or web read access. The target account is NOT required to have /Orchestration/protocol/CURRENT.md or any /Orchestration Library tree before bootstrap.
For an EXISTING project, preserve the protocol version in its own Protocol/adopted/ (or confirmed legacy INIT.md); obtain the exact historical release from local authorized files or GitHub if local copies are absent. Do not silently upgrade.
Do not treat a bundled, memorized, or hard-coded version (including 0.3.0) as current. Do not block solely because the Library's global CURRENT.md is missing. If GitHub cannot be read, report that precise blocker rather than inventing a version or claiming initialization succeeded.
Cross-project access is read-only and limited to authorized Orchestration discovery. Do not use files, context, or permissions from unrelated projects without explicit authorization.
